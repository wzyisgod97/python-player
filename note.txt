1、下载安装miniconda
2、Path配置miniconda环境变量
3、创建虚拟环境: conda create --name langchain1.2 python=3.14.6
  3.1: python --version 查看python版本
  3.2: conda env list 查看当前的python环境
4、初始化虚拟环境命令：conda init  
5、切换指定python环境：conda activate langchain1.2
   5.1:在langchain1.2环境中 执行python --version 来确认环境安装成功
6、在langchain1.2环境安装所需要的框架:
    6.1：pip install langchain==1.2.12 #安装1.2.12版本的langchain
    6.2：pip install langchain-openai  #安装chatopenAI依赖
    6.3：pip install langchain-deepseek #安装deepseek依赖
    6.4：pip install python-dotenv #安装环境管理的包
